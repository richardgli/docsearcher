<h1 align="center">docsearcher</h1>

<p align="center">Semantic search over your PDF documents. Find passages by meaning, not exact keywords.</p>

---

## Overview

PDFs are dense, and Ctrl+F only works when you remember the exact words. **docsearcher** lets you
describe the information you need in plain English and returns the most relevant passages from your
documents, then takes you straight to the source page in an integrated PDF viewer.

Upload a PDF, ask a question in natural language, and get back ranked passages with page numbers,
similarity scores, and previews. You can try it as a guest (documents held in memory for the
session) or sign in with Google to persist a searchable library.

## Features

- Upload PDFs via drag-and-drop or file picker
- Natural-language semantic search powered by vector embeddings
- Results ranked by cosine similarity, with page number, score, and text preview
- Integrated in-browser PDF viewer that navigates to the matching page
- Search within a single document or across your whole library
- Guest mode (no account) with an option to save documents after signing in
- Google OAuth sign-in and a persistent per-user document library
- Light / dark theme toggle
